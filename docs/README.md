# PayRakshak (AREA51) Documentation

This directory contains technical documentation, API specifications, evaluation results, UI designs/screenshots, and research reports for the PayRakshak prototype.

## Sections

- `architecture/`: System design, sequence diagrams, risk engine signal aggregation design.
- `api/`: OpenAPI specs, request/response payload examples, error handling definitions.
- `evaluation/`: Risk detection accuracy metrics, latency measurements, explanation clarity testing.
- `screenshots/`: Screenshots and screen recordings of the simulated payment flow.
- `report/`: Comprehensive project reports, threat models (APP scam vectors), and academic/practitioner write-ups.
