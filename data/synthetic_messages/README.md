# Synthetic Messages

Storage directory for synthetic urgency, phishing, and impersonation chat messages used to evaluate risk detection rules.

*Strictly synthetic test prompts only.*

## Included Datasets
- `synthetic_scam_messages.json`: Synthetic social-engineering & APP scam chat/SMS messages covering:
  - Accidental overpayment / fake refund lures
  - Electricity & utility disconnection threats
  - Customs & airport parcel impersonation
  - Part-time job / task deposit schemes
  - Benign peer-to-peer and merchant payments
