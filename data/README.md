# PayRakshak (AREA51) Synthetic Data Directory

> [!WARNING]
> **SAFETY & PRIVACY POLICY**:
> This directory is strictly designated for **synthetic, mocked test datasets**.
> Under NO circumstances may real:
> - UPI IDs or VPA addresses
> - Bank account numbers or IFSC codes
> - Real personal names, phone numbers, or credentials
> - Real financial transaction records
> be added to or committed into this repository.

## Directory Structure

- `synthetic_transactions/`: Mocked JSON/CSV records simulating benign and fraudulent UPI payment events.
- `synthetic_messages/`: Mocked text samples (SMS, WhatsApp, chat transcripts) exhibiting impersonation, refund lures, and urgent pressure.
- `evaluation/`: Benchmark datasets and evaluation ground truth for scoring false-positive and false-negative detection rates.
